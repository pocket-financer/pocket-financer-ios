# Security and Privacy Policy

Pocket Financer processes sensitive financial alerts entirely on the user's iPhone. Never place a real bank message, account identifier, phone number, transaction screenshot, signing credential, or model transcript in a public or private GitHub issue.

## Reporting a vulnerability

Do not open a regular GitHub issue for a security or privacy vulnerability.

1. Contact the repository owner (`@ManishAradwad`) through an agreed private channel first.
2. Describe the reproduction using 100% synthetic data.
3. Include the affected app version, iOS version, iPhone model, and whether the issue involves Shortcuts ingestion, local persistence/encryption, on-device model parsing, tombstoning, or local erasure.

GitHub private vulnerability reporting is not enabled on this private repository, so this policy intentionally avoids linking to an advisory form that would dead-end.

## Response process

Maintainers will confirm receipt, reproduce privately with synthetic inputs, assess whether stored evidence or transaction integrity is impacted, and coordinate a fix before any disclosure.
